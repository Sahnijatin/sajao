# Product flow and the intake brief

The flow is scan, brief, three designs, edit, buy. The brief should take under 90 seconds and be mostly taps, not typing.

1. **Scan.** A guided walk around the room with a live coverage meter. Bad scans are rejected on the phone before upload.
2. **Confirm.** She sees a simple floor plan, fixes anything wrong, and marks each existing item as keep, replace or remove.
3. **Brief.** The form below.
4. **Three designs.** Named by intent: Best value (about 80% of budget), Best match (at budget), Bold (a different layout, up to 10% over).
5. **Edit.** Drag, rotate, swap, lock items, regenerate around the locked ones. Budget total updates live.
6. **Buy.** Tap an item, or buy the whole room as a list.

A rearrange-only mode skips the brief and the catalog entirely and re-solves the layout with what she already owns. It is free to run and makes a strong free hook.

| Brief field | Input type | Why it matters |
| --- | --- | --- |
| Mode | Full makeover, refresh, rearrange only | Decides whether the catalog is used at all |
| What to include | Checklist: paint, lighting, sofa, chairs, tables, storage, bed, rug, curtains, wall art, decor, plants | Sets the shopping list |
| Budget | Slider plus "strict" or "can stretch 10%" | Hard constraint for the solver |
| Style | Swipe 8 to 10 room photos, like or dislike | Far more reliable than style words; needs no LLM |
| Reference | Upload a photo or paste a Pinterest link | Converted to a style vector |
| Colours | Pick loved and banned colours | Palette constraint |
| Who lives here | Kids, pets, elderly, work from home, guests | Safety, fabric and layout rules |
| Home type | Owned or rented | Rented means no drilling, no paint, movable items |
| Room use | Seats needed, TV or not, desk, storage need | Furniture program |
| Vastu | Off, light, strict | A scoring preference many Indian households want |
| Pincode | Auto or typed | Only show items deliverable to her |
| Brands | Preferred and blocked retailers | Filter |
| Timeline | Now, this month, in phases | Enables a staged buying plan |
| Anything else | Free text, optional | The only field the LLM must read |
